# Security Policy

## Reporting a Vulnerability

If you discover a security issue with this project (e.g., a compromised link, malicious redirect from the landing page, or supply chain concern with recommended tools):

1. **DO NOT** open a public issue
2. Email: [your-private-email@protonmail.com]
3. Include a description and steps to reproduce
4. We will respond within 72 hours

## Scope

This policy covers:
- The GitHub Pages landing page (`web/`)
- Links referenced in the zine and landing page
- The integrity of the PDF distribution files

This policy does **not** cover:
- Third-party tools we recommend (contact those projects directly)
- The Penpot platform itself (see [Penpot security](https://penpot.app))

## Link Integrity

All outbound links are checked periodically via CI. If you notice a link redirecting to an unexpected destination, please report it immediately.
