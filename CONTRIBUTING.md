# Contributing to Digital Privacy Pocket Toolkit

Thank you for wanting to contribute! This project thrives on community input.

## Ways to Contribute

### 🧰 Suggest a Tool
1. Open an issue using the "Tool Suggestion" template
2. Include: tool name, category, why it's privacy-respecting, link to source/open-source license
3. Wait for community discussion (we keep categories tight — usually 2–4 tools per slot)

### 🌍 Translate
1. Check [translations/README.md](../translations/) for active languages
2. If your language isn't listed, open an issue requesting it
3. Follow the [Translation Guide](docs/TRANSLATION_GUIDE.md)
4. You don't need design skills — just translate the text strings

### 🎨 Improve Design
1. Import the Penpot file from `src/penpot/` into [penpot.app](https://design.penpot.app)
2. Make your changes
3. Export the updated `.penpot` file and submit via Pull Request
4. Include screenshots of changes

### 🐛 Report Issues
- Broken links? Outdated tool recommendations? Typos?
- Use the "Bug Report" issue template
- Be specific about which page/section

## Editorial Criteria for Tool Inclusion

A tool **must meet ALL of these** to be considered:

- ✅ Does not sell user data to third parties
- ✅ Has a clear, accessible privacy policy
- ✅ Is either open-source OR has a genuinely free tier with privacy features intact
- ✅ Is actively maintained
- ✅ Can be used by non-technical people (or clearly notes the technical requirement)

A tool **may be removed** if:
- ❌ Acquired by a company with opposing privacy practices
- ❌ Adds tracking/analytics that weren't previously present
- ❌ Becomes unmaintained
- ❌ Community reports verified privacy concerns

## Pull Request Checklist

- [ ] All tool links are valid
- [ ] License headers/notes are correct
- [ ] If adding graphics, SVGs are properly licensed
- [ ] Penpot file exports cleanly to PDF
- [ ] Changelog updated
