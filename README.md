# 🛡️ Digital Privacy Pocket Toolkit

An open-source, editable, printable zine that helps everyday people discover privacy-respecting alternatives to the tools they already use.

**Scan. Swap. Share.**

![Zine Preview](web/assets/zine-preview.png)

## What This Is

A pocket-sized zine presenting mainstream services alongside privacy-focused alternatives — covering maps, AI, browsing, passwords, messaging, socials, and collaborative work. Designed to be printed, folded, distributed, and adapted by anyone.

## How to Use

### For Readers
1. Download the PDF
2. Print at home (A4 or Letter, double-sided)
3. Fold along the guides
4. Carry it. Share it. Leave it places.

### For Contributors
1. Fork this repo
2. Edit the Penpot file or suggest tool additions via Issues
3. Submit a Pull Request
4. See [CONTRIBUTING.md](CONTRIBUTING.md) for full guidelines

## Remix This

### For Translators
See [Translation Guide](docs/TRANSLATION_GUIDE.md) — no design skills needed for text-only translations.

## Editorial Principles

- **Tools must be open-source or fully free** (freemium acceptable if core privacy features are free)
- **No tool is recommended if it sells user data**
- **Decentralised and self-hostable options are preferred**
- **Mainstream equivalents are listed only for contrast**
- See [Design Principles](docs/DESIGN_PRINCIPLES.md) for full criteria
